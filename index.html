Menambahkan halaman Mushaf Pojok Kudus

  1. Siapkan gambar halaman yang sah digunakan dan sudah diverifikasi sesuai Mushaf Pojok Kudus yang Anda pakai.
  2. Masukkan gambar ke folder assets/mushaf/.
  3. Gunakan nama berurutan, misalnya 001.webp sampai 604.webp.
  4. Unggah folder beserta gambar ke GitHub. Agar sepenuhnya offline, buka web sekali saat online supaya aset tersimpan di cache.

Paket ini tidak menyertakan gambar 604 halaman, sehingga tidak mengklaim menampilkan mushaf asli sebelum aset yang benar ditambahkan.

Privasi

Jadwal dan riwayat disimpan di penyimpanan browser perangkat ini. Data tidak otomatis tersinkron ke perangkat lain. Jika data browser dihapus, data aplikasi dapat hilang—buat cadangan secara berkala.

Memasang ke GitHub Pages

  1. Buat repositori baru di GitHub.
  2. Unggah seluruh isi folder proyek ini (bukan hanya file ZIP).
  3. Buka Settings → Pages.
  4. Pada bagian build/deployment, pilih Deploy from a branch, branch main, folder /(root), lalu simpan.
  5. Tunggu beberapa menit, lalu buka alamat GitHub Pages yang diberikan.

GitHub Pages memerlukan internet untuk pertama kali dibuka. Setelah service worker aktif dan aset tersimpan, aplikasi bisa digunakan offline pada browser yang mendukungnya. Instalasi PWA biasanya memerlukan HTTPS.
